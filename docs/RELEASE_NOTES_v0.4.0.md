# WorkBuddy 小哇助手 v0.4.0

本次版本重点升级“摸一摸”互动，并重新拆分宠物大小、气泡字号和统计面板的尺寸规则。

## 摸一摸

- 三组随机动作：
  - 温柔摸头：闭眼、歪头、回正；
  - 开心蹦跳：举双手、蹦跳、耳朵和尾巴摆动；
  - 害羞捂脸：双爪贴脸、轻微摇晃。
- 动作随机且不会连续重复；
- 每组动作有独立气泡文案池；
- 保留爱心粒子；
- 动画使用 24fps 透明 WebP，不使用低质量 GIF；
- 收尾改为即时切换并保留基础立绘回弹，不再出现双影或闪烁。

## 显示设置

- “宠物大小”只缩放小猫本体，不再影响气泡和统计面板；
- 新增“气泡字号”设置，可在 10–18px 之间独立调整；
- 气泡固定宽度，文字变大时向上扩展；
- 气泡锚定在小猫实际头顶上方，缩小宠物时不会飘得过远；
- 展开统计面板时固定为 `1040×810`，宠物列固定 `300px`。

## 修复

- 清除尾巴环内残留的品红背景；
- 统一动作素材的透明边缘；
- 修正设置页部分样式未生效的问题。

## 升级

已安装 `v0.3.0` 的用户可以在设置页“版本与更新”中检查并安装更新。也可以直接下载本版本覆盖安装。

## 已知限制

- 仅支持 Windows 10/11 x64；
- 当前构建尚未配置商业代码签名证书，Windows 可能显示“未知发布者”；
- 动画结束仍采用干净的即时切换，不进行跨姿势透明混合，以避免双影。
