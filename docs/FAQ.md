# 常见问题

## 启动后提示“未找到 WorkBuddy 本地数据”

请确认：

1. 本机已经安装 WorkBuddy；
2. 已登录并至少创建过一次会话；
3. WorkBuddy 已经正常写入过用量数据；
4. 小哇和 WorkBuddy 使用同一个 Windows 用户运行。

数据出现后，小哇会在下一次刷新时自动读取。

## 面板里没有积分或 Token

可能是以下原因：

- 当前 WorkBuddy 版本尚未写入对应记录；
- 会话使用了不支持统计的模型；
- 数据记录尚未完成；
- 日期筛选区间内没有请求。

可以切换到“全部时间”或打开“请求明细”确认原始记录。

## 提示“数据结构不兼容”

WorkBuddy 升级后可能调整了本地数据结构。请先更新到最新版小哇；如果最新版仍不兼容，请提交 Issue，并附上：

- 小哇版本；
- WorkBuddy 版本；
- 错误提示文字。

不要上传完整数据库或真实会话内容。

## 提示“WorkBuddy 数据正在被占用”

WorkBuddy 正在写入数据库时，小哇可能暂时无法读取。应用会自动重试。如果持续出现，请关闭并重新打开 WorkBuddy。

## 日期筛选为什么和预期不同

趋势、会话排行和请求明细按请求日期统计。

无法精确关联到单次请求的积分，会按该会话最后活跃日期归入区间。因此跨区间汇总时可能与 WorkBuddy 原始记录存在少量差异。

## 小猫挡住了其他窗口

- 拖动小猫可以调整位置；
- 在设置中降低尺寸或透明度；
- 关闭面板后应用会隐藏在系统托盘；
- 右键托盘图标可以彻底退出。

## 如何更新小哇

打开设置页，在“版本与更新”中点击“检查更新”。发现新版本后先下载，下载完成后再选择“重启并安装”。启动时自动检查可以单独关闭。

更新机制与故障排查见 [自动更新说明](UPDATES.md)。

## 为什么没有收到完成通知

请检查：

- “完成通知”是否开启；
- 是否处于免打扰时段；
- 后台任务通知是否开启；
- WorkBuddy 会话是否真的从执行中变为完成。

## 为什么有两个快捷方式

升级早期测试版本后，旧快捷方式可能残留。请通过旧版卸载程序卸载，再安装新版本；必要时手动删除旧的乱码快捷方式。

## Windows 提示未知发布者

当前版本可能未进行代码签名，因此 Windows SmartScreen 会显示提示。请确认安装包来自本仓库 Releases，并核对 `SHA256SUMS.txt`。

## 卸载会删除我的 WorkBuddy 数据吗

不会。卸载程序只删除小哇的安装文件和快捷方式，不删除 WorkBuddy 自身的数据。

## 支持 macOS 或 Linux 吗

目前仅支持 Windows x64。其他平台尚未验证。

## 会上传我的会话吗

不会。会话数据只在本机读取，详细说明见 [隐私说明](../PRIVACY.md)。
