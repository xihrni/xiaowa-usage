# WorkBuddy 小哇助手 v0.1.0

首个社区预览版。

小哇是一个读取 WorkBuddy 本地用量数据的 Windows 桌面宠物。平时安静待在桌面，需要时展开面板查看会话积分、Token 构成、历史趋势和请求明细。

## 下载

- `WorkBuddyPet-Setup-0.1.0.exe`：推荐，普通用户安装版；
- `WorkBuddyPet-0.1.0-win-x64.zip`：免安装便携版；
- `SHA256SUMS.txt`：发布文件校验值。

## 功能

- 透明桌面宠物与系统托盘；
- 处理中、完成、停止和失败通知；
- 支持通知合并、提示音与免打扰时段；
- 单会话、全部会话和今日用量统计；
- 自定义日期区间与账期筛选；
- 每日积分趋势、模型消耗和区间汇总；
- 会话排行与请求明细；
- 本地只读，不上传会话内容。

## 系统要求

- Windows 10/11 x64；
- 已安装并登录 WorkBuddy；
- WorkBuddy 中已有至少一次会话记录。

## 使用说明

安装版运行后从桌面或开始菜单启动。便携版需完整解压后双击 `WorkBuddyPet.exe`。

单击小猫开合统计面板，拖动小猫调整位置。关闭面板后应用会隐藏在系统托盘。

## 隐私

小哇只读取当前 Windows 用户的 WorkBuddy 本地数据，不上传会话标题、消息内容、积分或 Token，不包含遥测和广告。

## 注意事项

- 这是第三方社区工具，不是 WorkBuddy 官方产品；
- 当前版本未进行代码签名，Windows 可能显示 SmartScreen 提示；
- 仅支持 Windows x64；
- WorkBuddy 数据结构变化时可能出现不兼容，请反馈错误提示；
- 对外分享截图前请检查是否包含真实会话标题。

完整说明见仓库 README、PRIVACY.md 和 docs/FAQ.md。
