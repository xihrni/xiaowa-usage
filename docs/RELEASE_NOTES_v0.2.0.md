# WorkBuddy 小哇助手 v0.2.0

本次版本加入自动更新、启动问候和快捷方式图标修复。

## 新增

- 设置页“版本与更新”：
  - 查看当前版本；
  - 手动检查 GitHub Release；
  - 确认后下载更新；
  - 下载完成后重启安装；
  - 可关闭启动时自动检查。
- 启动欢迎语：
  - 按本地时间区分清晨、上午、中午、下午、晚上和深夜；
  - 使用宠物气泡展示约 5 秒后自动隐藏；
  - 启动时已有运行中的任务，也不会立即覆盖欢迎语。

## 修复

- 安装后桌面、开始菜单和系统卸载信息仍显示 Electron 默认图标的问题；
- 安装目录新增独立 `icon.ico`，快捷方式直接引用该图标；
- 应用启动时会自动修复旧快捷方式的图标路径，升级用户同样生效。

## 分发与构建

- 版本提升至 `0.2.0`；
- GitHub Actions 自动生成 NSIS 安装包、便携 ZIP、`latest.yml`、blockmap 和 SHA-256；
- 下载页自动显示最新版本；
- 安装包补充完整的版权、发布者和官网信息。

## 升级说明

`v0.1.0` 未包含更新器。已经安装 `v0.1.0` 的用户需要手动安装一次 `v0.2.0`。从 `v0.2.0` 开始，后续版本可以通过设置页检查并安装更新。

## 已知限制

- 仅支持 Windows 10/11 x64；
- 当前版本尚未配置商业代码签名证书，Windows 可能显示“未知发布者”；
- 自动更新的跨版本完整链路将在下一个版本发布时继续验证；
- WorkBuddy 数据结构升级后仍可能需要适配。
