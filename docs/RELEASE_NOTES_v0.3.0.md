# WorkBuddy 小哇助手 v0.3.0

本次版本加入小猫右键菜单和互动能力。

## 新增

- 右键单击小猫显示原生菜单：
  - 摸一摸；
  - 打开 WorkBuddy；
  - 打开面板；
  - 隐藏小哇；
  - 退出。
- 左键行为保持不变，仍然用于展开或收起统计面板；
- 面板已经展开时，“打开面板”自动禁用。

## 摸一摸

- 使用招手立绘播放轻微弹跳；
- 冒出爱心粒子；
- 随机显示一句互动文案；
- 约 2.5 秒后恢复原来的工作或待机状态；
- 互动期间暂时覆盖任务气泡，结束后恢复正常显示。

## 打开 WorkBuddy

- 能从常见安装位置找到 WorkBuddy；
- 优先尝试激活已有窗口；
- Windows 聚焦受限时使用 `workbuddy://` 协议兜底；
- 找不到时显示提示气泡，不静默失败。

## 修复

- 修复样式表中未闭合规则导致设置页更新卡片和新动画样式失效的问题。

## 升级

已经安装 `v0.2.0` 的用户可以在设置页的“版本与更新”中检查更新，也可以直接下载本版本安装包覆盖安装。

## 已知限制

- 仅支持 Windows 10/11 x64；
- 当前构建尚未配置商业代码签名证书，Windows 可能显示“未知发布者”；
- 多设备与不同 WorkBuddy 版本的完整兼容性验证仍暂缓。
